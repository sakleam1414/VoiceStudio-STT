# Voice Studio STT

Речь в текст и субтитры в Discord через Tailscale или Radmin VPN.

[Скачать последнюю версию](https://github.com/sakleam1414/VoiceStudio-STT/releases/latest)

## Установка

1. Скачайте `STT-for-friend-*.zip` в Releases и распакуйте целиком в папку BetterDiscord `plugins`.
2. Запустите `stt_server.exe` и выбранный VPN на каждом компьютере. Для Radmin VPN вступите с другом в одну сеть.
3. На ПК говорящего включите **Microphone**; на принимающем ПК — **Subtitles**.
4. Выберите говорящих в панели участников Subtitles.

Python не нужен для готового EXE. EXE содержит Vosk; дополнительные движки устанавливаются через Python отдельно. Модели скачиваются при первом выборе.

При первом запуске EXE автоматически создаёт одну запись **Voice Studio** в автозагрузке Windows. Она запускает `stt_server.exe --background` без консоли. Закрытие окна оставляет сервер работать. Старые записи `bd_stt_server.bat` и `stt_server_autostart.bat` заменяются с резервной копией в `.stt-startup-backup`. Управлять автозагрузкой можно через диспетчер задач Windows; отключённая пользователем запись не включается заново.

## Адреса друзей: автоматически и вручную

Нужен общий VPN: Tailscale или Radmin VPN. Одного Radmin у вас и одного Tailscale у друга недостаточно — оба должны подключиться к одной сети выбранного VPN. В Microphone и в окне участников Subtitles есть кнопка **Мой адрес и адреса друзей**. В общем окне можно выбрать участника голосового канала, чтобы связать адрес с его Discord ID:

1. Нажмите **Скопировать мой адрес** и отправьте адрес другу в сообщении.
2. Обычно друг найдётся автоматически. Если нет — нажмите **Адрес** возле его имени в Subtitles и вставьте его `100.x.x.x` для Tailscale или `26.x.x.x` для Radmin VPN. Можно добавить порт, например `26.10.0.2:8765`.
3. Нажмите **Проверить адрес**, затем **Сохранить адрес**. Для другого друга сохраняется отдельный адрес.
4. Можно изменить или удалить адрес. При недоступном друге адрес сохраняется для следующего подключения.

Адрес сверяется с Discord ID. Автопоиск остаётся включён; при недоступном автоматическом адресе используется проверенный ручной. Передача ограничена участниками текущего голосового канала. ПК говорящего с одним Microphone тоже умеет сохранять адреса получателей.

Поддерживаются IPv4 Tailscale `100.64.0.0/10` и Radmin VPN `26.x.x.x`, включая отдельный порт. Автопоиск доступен для Tailscale; адрес Radmin вводится вручную. Для входящих соединений Radmin сервер дополнительно проверяет, что запрос пришёл на IP действующего адаптера Radmin. Панель управления остаётся доступна только локально. Ручной адрес не отменяет общий VPN и запуск сервера у друга. Если старый сервер ещё не поддерживает копирование своего адреса, обновите сервер или скопируйте Tailscale IPv4 из приложения Tailscale.

Адреса, имена и привязки друзей хранятся только локально в `stt_peers.json`. Этот файл исключён из Git, релизов и установки обновлений. Копировать его между разными пользователями не требуется.

## Обновление у друга

Все обновления находятся в окне **Voice Studio** (`stt_server.exe`). Проверка выполняется при открытии окна и каждые 6 часов; кнопка **Проверить ↻** запускает её сразу. Для Subtitles и Microphone показаны фактические версии файлов: зелёный — актуальная версия, жёлтый — доступна новая. Если GitHub недоступен, установленная версия остаётся видна, но не обозначается актуальной.

Кнопка **Установить** доступна, когда устарел хотя бы один компонент. Она обновляет только устаревшие сервер/плагины; актуальные пропускаются. При установке один раз скачивается ZIP релиза; из него извлекаются и проверяются только нужные компоненты. Общие файлы устанавливаются один раз. При обычной проверке версий ZIP не скачивается. При обновлении сервера он перезапускается. В плагинах кнопок проверки и установки обновлений нет.

Перед заменой проверяется SHA256 всех файлов. Предыдущая копия сохраняется в `.stt-update-backup`. Если установка не удалась, заменённые файлы восстанавливаются. Настройки `*.config.json`, модели и история не входят в обновление. При ошибке сети остаётся установленная версия. Если BetterDiscord не перезагрузил плагин сам, выключите и включите его.

## Как выпустить новую версию

`VERSION.json` — единственное место, где задаются версии релиза и компонентов. Пример следующего обновления только Microphone:

```powershell
python tools/release.py --release 1.8.3 --microphone 2.7.2
```

Скрипт сам изменит `@version` и версию в интерфейсе Microphone. Для сервера используйте `--server`, для Subtitles — `--subtitles`. Меняется номер вместе с исправленным кодом. Один номер без нового кода не добавляет исправлений.

Проверьте изменения и отправьте commit с тегом:

```powershell
git add .
git commit -m "Update Microphone"
git push origin main
git tag v1.8.3
git push origin v1.8.3
```

GitHub Actions на Windows соберёт EXE и опубликует **только один ZIP**. Инструкции, значки, контрольные суммы и манифест находятся внутри архива. Небольшие данные для проверки версий добавляются в скрытый комментарий описания релиза; отдельных вложений для них нет. У клиентов будет отображаться `Microphone 2.7.1 → 2.7.2`; версии остальных компонентов не меняются. Публикация обновления — отправка тега, она не происходит при обычном редактировании файла.

Для локальной сборки:

```powershell
python -m pip install -r stt_requirements.txt pyinstaller==6.21.0
./tools/build-exe.ps1
```

Результат находится в `release/`. Источник релизов задаётся в `stt_update.json`.

## Разработка

```powershell
python -m py_compile stt_server.py tools/release.py
node --check microphone.plugin.js
node --check subtitles.plugin.js
node --check stt_updates.js
```

Личные конфиги, логи, модели, EXE и ZIP не отправляются в Git. Готовые бинарные файлы размещаются в Releases.

### Совместимость с BetterDiscord

Сетевой помощник из `stt_updates.js` встраивается в оба плагина: загрузчик внешних JS-модулей некоторых версий BetterDiscord вызывает `compileFunction` с неправильными параметрами. После изменения помощника выполните `python tools/bundle-network.py`. Скрипт выпуска делает это автоматически, а CI проверяет совпадение встроенного кода с источником.

### Переход на один ZIP

Для версий 1.8.1 и старше один раз скачайте ZIP нового релиза и распакуйте его в папку `plugins` с заменой файлов. Старый обновлятор ожидает отдельные вложения; новый обновляется из единого ZIP. Личные конфиги и `stt_peers.json` в архив не включаются.

### Tailscale или Radmin VPN

Tailscale — основной вариант с автопоиском. Radmin VPN — дополнительный вариант для Windows с ручными адресами. В «Мой адрес и адреса друзей» выберите VPN, скопируйте свой адрес, отправьте другу и сохраните его IP возле участника. Наличие адаптера Radmin не означает, что друг уже в сети: это проверяется отдельно по адресу. Диапазон 26/8 не сканируется, проверяются только сохранённые адреса. Использовать обе программы одновременно не требуется.
