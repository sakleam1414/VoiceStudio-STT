STT 1.6.0 · Windows x64

УСТАНОВКА
Распакуйте весь ZIP в папку BetterDiscord plugins. Запустите stt_server.exe.
Python для EXE не нужен. На каждом ПК запустите Tailscale в одной сети.
Говорящему нужен Microphone; получающему — Subtitles. Выберите участников.
Модели скачиваются при первом выборе. Личные конфиги и модели в ZIP не входят.

ОБНОВЛЕНИЯ
Источник: https://github.com/sakleam1414/VoiceStudio-STT/releases/latest
Проверка при запуске и каждые 6 часов. В плагине нажмите «Проверить обновление»,
затем «Установить обновление». В окне сервера: «Обновить» и «Установить».
Версии компонентов отдельные: Microphone 2.5.0, Subtitles 1.9.0, сервер 1.6.0.
Файлы проверяются по SHA256; старая копия сохраняется в .stt-update-backup.
Настройки и модели сохраняются. Сервер при обновлении перезапускается.
Если BetterDiscord не перезагрузил плагин сам, выключите и включите его.

ПОДРОБНЕЕ
Инструкция выпуска: https://github.com/sakleam1414/VoiceStudio-STT#readme
stt_server.bat --check проверяет зависимости и каталог.
Журнал ошибок: stt_server.log. Порт STT 5000, субтитры 8765.
Разрешите stt_server.exe в брандмауэре для Tailscale.
Для дополнительных движков используйте Python 3.12 x64 и stt_install.bat.

АДРЕСА ДРУЗЕЙ
В Microphone / Subtitles: «Мой адрес и адреса друзей».
«Скопировать мой адрес» — отправьте адрес другу сами.
Для ручного подключения: «Адрес» возле друга → вставить 100.x.x.x →
«Проверить адрес» → «Сохранить адрес». Для каждого друга адрес отдельный.
Автопоиск остаётся включён. Tailscale и сервер должны работать у обоих.
Адреса хранятся локально в stt_peers.json и сохраняются при обновлении.
